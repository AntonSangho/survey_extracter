# ArUco 마커 (양식 모서리용)

사전: `DICT_4X4_50`, 이미지 600×600px (검은 테두리 포함, 흰 여백 없음).

| 파일 | ID | 위치 |
|---|---|---|
| `aruco_4x4_50_id0.png` | 0 | 좌상 |
| `aruco_4x4_50_id1.png` | 1 | 우상 |
| `aruco_4x4_50_id2.png` | 2 | 좌하 |
| `aruco_4x4_50_id3.png` | 3 | 우하 |

- 인쇄 크기: **12mm × 12mm** (최소 10mm), 종이 가장자리에서 **6mm** 안쪽
- 마커 둘레에 흰 여백 3mm 이상, 마커를 늘리거나 회전·반전하지 않기(정사각형 유지)
- 이미지를 키울 때는 부드럽게 보정하지 말고 그대로 쓰기(번지면 인식률이 떨어짐)
