# 양식·스캔 가이드

설문지를 나눠 주고 걷어 스캔할 때 지킬 내용입니다. 근거는 [양식 제안](form_design_proposal.md)에 있습니다.

## 양식 샘플 문서

- [`form_sample.md`](form_sample.md): 제안 양식을 마크다운으로 옮긴 문서입니다. 구글 독스에 붙여넣어 보존·편집할 수 있습니다. (독스의 마크다운 붙여넣기 설정이 켜져 있어야 서식이 적용됩니다. 설정 위치는 구글 독스 버전에 따라 다를 수 있으니 붙여넣은 뒤 제목·표가 제대로 나오는지 확인하세요.)
- 인쇄·스캔용 원본은 [`templates/proposed_form.pdf`](../templates/proposed_form.pdf)입니다. 마커와 칠하는 버블은 PDF에만 있습니다.
- 학교명 등을 바꾸려면 `python tools/make_proposed_form.py templates/proposed_form.pdf --school "OO초등학교"`, `python tools/make_form_markdown.py docs/form_sample.md --school "OO초등학교"`를 실행합니다.

## 학생에게 안내할 말 (작성 방법)

- 연필이나 **가는 펜(0.7mm 이하)** 으로 쓰세요. 굵은 펜·형광펜·사인펜은 쓰지 마세요. (획이 번져서 글씨를 읽을 수 없어요.)
- 고르는 문항은 **동그라미 안을 가득 칠하세요.** V 체크나 동그라미 치기는 안 돼요.
- 잘못 칠했으면 그 칸에 **큰 X 표시**를 하고, 맞는 칸을 새로 칠하세요.
- 하고 싶은 말은 **네모 칸 안에** 쓰세요. 이름이나 친구 이름은 쓰지 않아요.
- 한 문항에는 한 칸만 칠하세요.

## 설문 진행 담당자 (교사/진행자)

- 학교명이 사전 인쇄된 양식을 사용하세요(학교별 PDF 출력).
- 연필/가는 펜을 미리 나눠 주세요.
- 걷은 설문지는 **학교별로 분리**해 두세요(스캔 폴더 이름이 학교명이 됩니다).
- 구겨지거나 찢어진 설문지는 펴서 스캔하세요.

## 스캔 설정 권장

| 항목 | 권장 | 비고 |
|---|---|---|
| 해상도 | 300dpi (최소 200dpi) | 100dpi 이하는 작은 글씨를 읽기 어려움. 체크박스만 보면 75dpi까지도 됨 |
| 색상 | 8비트 그레이스케일 | 1비트 흑백은 굵은 펜이 뭉개짐. (이번 데이터는 1비트였고, 그레이가 더 좋은지는 아직 미검증) |
| 파일 형식 | PNG, 또는 JPEG 품질 60 이상 | JPEG q30까지 체크박스 판독에는 영향 없었으나 글씨 번짐 우려로 q60 이상 권장 |
| 방향 | 가급적 같은 방향 | 180° 뒤집힘은 자동 보정됨(이번 389/422장) |
| 용지 | A4 | 크기가 다르면 정합 실패 가능 |
| 기타 | 스캐너 유리 청소 | 스캐너 유리의 얼룩이 세로줄 노이즈로 찍힐 수 있음 |

## 파일명

스캔 파일명이 곧 이미지 ID가 됩니다. **중복되지 않게** 하세요(같은 이름이 다른 폴더에 있으면 `학교명_파일명`으로 구분됩니다). 추출 후에는 파일명을 바꾸지 마세요(검토 결과·드라이브 링크와 연결됨).

## 이중 체크 판정 규칙 (검토자용)

[double_check_rules.md](double_check_rules.md)에 정리했습니다. 요약: 지운 흔적 쪽은 제외하고, 이웃 칸에 걸쳤으면 체크 꼭짓점이 있는 칸을 고르며, 한 칸을 정할 수 없을 때만 `무효`, 표시가 없으면 무응답으로 둡니다.
