# 이중 체크 판정 규칙

체크박스 문항에서 자동 판독이 답을 확정하지 못했을 때(검토 화면에서 플래그가 붙은 문항) 사람이 어떻게 판정하는지 정리한 규칙입니다. 이번 검토(422장, 플래그 113건)의 실제 판정 결과를 집계해서 만들었습니다.

> **상태:** 확정. 검토 담당자가 실제 적용한 기준과 같음을 확인했다(2026-10-01). "집계 결과"는 이번 검토에서 읽은 사실이다.

## 플래그 종류

| 플래그 | 의미 | 자동 판독 결과 |
|---|---|---|
| `multi` | 한 문항에서 두 칸 이상에 표시가 있음(이중 체크) | 답을 비워 둠(후보만 기록) |
| `blank` | 어느 칸에도 표시가 없음 | 답을 비워 둠 |
| `low_margin` | 1순위와 2순위 점수 차이가 애매함 | 답을 비워 둠 |
| `filled:<칸>` | 해당 칸이 거의 칠해져 있음(낙서·칠해서 지운 흔적 가능성) | 참고 표시 |

## 집계 결과 (이번 검토)

| 플래그 | 건수 | 최종 판정 |
|---|---|---|
| `multi` | 90 | 최고점 칸 76(84%), 2순위 칸 13(14%), 무응답 1 |
| `blank` | 11 | 모두 무응답(빈 값)으로 확정 |
| `low_margin` | 6 | 모두 최고점 칸 |

- **`무효`로 판정한 문항은 0건**이었다. 이중 체크라도 모두 한 칸을 골랐다.
- 이중 체크의 대부분(75%, 90건 중 67건)은 **서로 이웃한 칸**에 걸쳐 있었다. 체크(✓)의 긴 획이 옆 칸을 침범한 경우로 보인다.
- `multi`에서 점수 차이로는 정답을 가를 수 없었다. 최고점이 정답인 경우의 2순위/1순위 점수 비율은 평균 0.56(0.18~0.97), 2순위가 정답인 경우는 평균 0.61(0.20~0.98)로 겹친다. **점수는 참고만 하고 원본을 보고 판정한다.**
- 2순위를 고른 13건 중 `filled` 플래그가 붙은 것은 2건뿐이라, 대부분은 점수 외의 단서(지운 흔적, 획의 꼭짓점 위치 등)를 눈으로 보고 판단한 것으로 보인다.

## 판정 기준

검토 화면의 `원본 보기`(똑바로 세운 원본)와 오버레이를 보고 순서대로 적용합니다.

1. **지운 흔적이 있는 칸은 제외하고** 남은 칸을 선택한다. 지운 흔적 = 칸을 덮어 칠한 낙서, 큰 X 표시, 줄로 그어 지운 표시.
2. 이웃한 두 칸에 걸친 경우, **체크의 꼭짓점(획이 꺾이는 곳)이 있는 칸**을 선택한다. 긴 꼬리 획만 걸친 칸은 선택하지 않는다.
3. 점수가 높은 칸이 정답일 가능성이 높지만(이번 84%), 2·3번으로 확인되지 않으면 점수만으로 정하지 않는다.
4. 위 방법으로도 한 칸을 정할 수 없고, 두 칸 모두 같은 강도로 의도적으로 표시했다면 **`무효`로 입력하고 담당자에게 검토를 요청**한다. `export`가 무효 판정 목록을 `검토요청` 시트(문항, 원본 파일, 공유링크)와 실행 결과로 알려 준다. (이번 검토에서는 적용된 적 없음)
5. 아무 표시도 없으면(`blank`) 무응답(빈 값)으로 둔다. 추측으로 채우지 않는다.
6. 이 판정은 `review_decisions.csv`와 최종 파일의 `검토이력` 시트에 자동값 → 최종값으로 남는다. 판단 근거를 따로 적어야 하면 `corrections.csv`를 쓴다.
